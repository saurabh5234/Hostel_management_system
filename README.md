# Hostel Management System

A full-stack web application to manage hostel operations such as rooms, tenants/students, payments, maintenance, and reports.

Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express
- Database: (MongoDB )
- Authentication: JWT (Role-based access: Admin, Student)

 Features
- Admin dashboard with room, tenant, payment, and maintenance management
- Student dashboard to view room details and payment status
- Secure authentication & authorization
- Reports & analytics (revenue, occupancy)
